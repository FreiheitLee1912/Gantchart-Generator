# Gantt Chart Generator v3

Jira CSV から業務報告用のガントチャートを作成し、PowerPoint として出力するための v3 版です。

## Cloud Usage

GitHub Pages で公開されている場合は、リポジトリの Pages URL を開くと v3 が起動します。

ローカルで使う場合は `index.html` をブラウザで開いてください。

## Main Files

- `index.html`: v3 の起動画面
- `app_v3.js`: v3 の処理本体
- `styles_v2.css`: 画面スタイル
- `vendor/`: PPTX 出力に必要なライブラリ
- `BUSINESS_GUIDE_V3.md`: 業務向け説明書

## Notes

このリポジトリは v3 の配布・クラウド実行用です。
